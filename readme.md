#  Rock, Paper, Scissors Web Game

A lightweight, interactive Rock, Paper, Scissors game built using vanilla JavaScript and DOM manipulation. The game features an computer opponent and uses a modal popup to declare the round's winner before resetting for a new match.

---

##  Features


* **Interactive Modals:** Game results are displayed cleanly inside a modal popup window rather than using basic browser alerts.
* **Auto-Reset Loop:** Clicking either the "OK" or "Close" buttons on the modal clears the state and reloads the page for a seamless new round.
